ADMET: The evaluation of pharmacokinetics and toxicity is crucial for the design of new therapeutic candidates. In silico virtual screens and generative AI output a vast number of molecules that must be filtered to a tractable number for synthesis and experimental validation. An effective primary filter is to evaluate candidate compounds based on their Absorption, Distribution, Metabolism, Excretion, and Toxicity (ADMET) properties.

ChemXplore: ChemXplore is an advanced molecular analysis platform for predicting ADMET properties using state-of-the-art machine learning models with intuitive visualization.

Models: ChemXplore predicts ADMET properties using a graph neural network architecture called Chemprop-RDKit. Our models were trained on 41 ADMET datasets from the Therapeutics Data Commons (TDC) and achieve the highest average rank on the TDC ADMET Benchmark Group leaderboard.

Input

Molecules: ChemXplore can analyze up to {{ "{:,}".format(max_molecules | default(1000)) }} molecules simultaneously through SMILES input, CSV upload, or interactive molecular drawing.

DrugBank Reference: Compare your molecules against {{ "{:,}".format(drugbank_total_size | default(10000)) }} approved drugs from DrugBank, filtered by Anatomical Therapeutic Chemical (ATC) codes for relevant context.

Output

Interactive Visualizations: Dynamic summary plots and radial visualization charts showing ADMET properties with percentile comparisons to DrugBank reference sets.

Comprehensive Predictions: 8 physicochemical properties and 41 ADMET predictions with confidence metrics and downloadable results.

ChemXplore can be deployed locally as a command line tool for high-throughput batch processing or integrated as a Python module within existing drug discovery pipelines.

pip install chemxplore
